# EnterprizeCalc
Рипозиторий создан в обучающих цклях для темонстрации возможностей раширения и поддержки программы при проектироапнии через архитектуру MVP
Большая часть реализаций в этом коде - намеренные упрощения для облегчения восприятия темы.

Разбор паттернов и решение экзаменационного задания: [Ответ.txt](Ответ.txt).

Добавлена операция `%` - остаток от деления, в том числе для дробных чисел.
Вводится знак операции, например `%`, а не номер строки меню.

Сборка: открыть `EnterprizeCalc.sln` в Visual Studio 2022 с компонентами
разработки на C++, выбрать Debug / x64 и назначить `consoleUI` запускаемым проектом.
Тесты находятся в проекте `CalculatorUnitTest`.
